## Smart Fridge: Food Directory System (by JiakPeng)

A Smart Fridge System that tracks stored items, expiry dates and remind users about food that is expiring

## Tech Stack
- HTML
- CSS (Bootstrap)
- JavaScript
- Flask (Backend)  
- Python (IoT integration)

### Hardware
- microphone
- Webcam

## Feature
### Voice Command
- insert new food into the list
- list food expiring in a week

### Web App
- display food that are in the fridge
- highlight expiring or expired food
- alternative interface to add new food items manually
